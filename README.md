# Three.js 简易收集小游戏
一个用Three.js制作的极简小游戏，控制绿色立方体收集红色球体得分。

## 玩法
- 绿色立方体：玩家角色
- 操作：按W/A/S/D或方向键移动
- 目标：碰到红色球体得分，球体随机刷新位置

## 运行方法
1. 克隆仓库：`git clone https://github.com/你的用户名/threejs-collect-game.git`
2. 打开`threejs-game.html`文件（直接用浏览器打开即可）

## 技术栈
- Three.js（v0.160.0）
- HTML/CSS/JavaScript
